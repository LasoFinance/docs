## What is Laso Finance?

Laso Finance is a payment API that lets AI agents spend cryptocurrency. Using the [x402 protocol](https://www.x402.org/), agents can programmatically order USA and international prepaid cards, gift cards, and send USD/EUR/GBP to debit cards with USDC on Base or Solana.

Agents can also open **real banking rails** for their account: a US bank account that converts incoming dollars into USDC, and a payout address that converts USDC back into dollars in a bank account. An agent drives the whole setup itself, including reading back its own routing and account numbers. The only step reserved for a human is identity verification.

And with a **Laso-managed wallet**, an agent can settle x402 challenges anywhere on the open web, not only on Laso's own endpoints.

No API keys needed. Agents pay per request with crypto, and the x402 protocol handles authentication automatically.
